# Flamingo Emma - Vision & Stratégie

Un site web moderne présentant la vision, la stratégie et l'univers de Flamingo Emma, avec une esthétique "Pink Vibes" et "Soft Life".

## 🎨 Caractéristiques

- **Design Responsive** : Optimisé pour tous les appareils (mobile, tablette, desktop)
- **Esthétique Pink Vibes** : Palette de couleurs douce et moderne
- **Sections Complètes** :
  - Vision et piliers de contenu
  - Analyse détaillée de chaque plateforme (YouTube, TikTok, Instagram, Facebook, Fanvue)
  - Stratégie unifiée et entonnoir de conversion
  - Calendrier éditorial interactif de 30 jours
  - Métriques et plan d'optimisation
  - Appel à l'action

## 🚀 Technologies Utilisées

- **Vite** - Build tool rapide et moderne
- **React 19** - Framework JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **PostCSS & Autoprefixer** - Traitement CSS avancé

## 📦 Installation

```bash
# Cloner le projet
git clone <repository-url>
cd flamingo-emma-vision

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Construire pour la production
npm run build

# Prévisualiser la build
npm run preview
```

## 🎯 Contenu Principal

### Vision
Les 4 piliers de contenu :
- 🌸 Soft Life & Pink Vibes
- 🤖 Créations IA & Esthétique Onirique
- 🌧️ Relaxation & Ambiance Sonore
- 💭 Storytelling Personnel & Communauté

### Plateformes Analysées
1. **YouTube** - Cœur de l'Ambiance
2. **TikTok** - Moteur de Découverte
3. **Instagram** - Vitrine Lifestyle
4. **Facebook** - Hub Communautaire
5. **Fanvue** - Destination Monétisation

### Stratégie
Entonnoir de conversion en 4 étapes :
1. Découverte (TikTok, YouTube Shorts, Reels)
2. Consommation (YouTube Long, Instagram Posts)
3. Attachement (Instagram Stories, Facebook)
4. Conversion (Fanvue, Beacons)

Calendrier éditorial interactif de 30 jours avec :
- Idées de publications
- Modèles de texte
- Hashtags recommandés
- Horaires optimaux

## 🎨 Personnalisation

### Couleurs
Modifiez les couleurs dans `tailwind.config.js` :
```javascript
colors: {
  'pink-soft': '#FFB6D9',
  'pink-pale': '#FFC9E3',
  'pink-deep': '#FF69B4',
  'rose-light': '#FFE4F0',
  'flamingo': '#FF1493',
}
```

### Contenu
Modifiez le contenu directement dans les fichiers des composants dans `src/components/`.
